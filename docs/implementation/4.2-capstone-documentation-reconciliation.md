## Delivered and deferred boundaries

- [#952](https://github.com/klum-dsl/klum-ast/issues/952): ordered execution, commands, qualified converters, owned
  sequences, native derived-key Maps, virtual scopes and finite literal Map aliases are delivered. Broader operation,
  polymorphic, reference and composition grammar remains deferred; the support inventory records exact exclusions.
- [#953](https://github.com/klum-dsl/klum-ast/issues/953): public common/keyed Factory creation, active-Builder application,
  keyless Template recipes, ordinary-root overlays and Builder-body schema selection are delivered. Parser/file/URL
  loading remains deferred. Ordinary roots run lifecycle and validation; Template construction defines a recipe.
- [#959](https://github.com/klum-dsl/klum-ast/issues/959): numeric and conservative Pattern projection, field policy,
  documentary controls, bounded first-level composition and contract/catalog separation are delivered. Size, broader
  mappings, contextual/default projection and full quantity grammars remain deferred.
- [#981](https://github.com/klum-dsl/klum-ast/issues/981): selected compiled String-converter parameter facts, independent
  projection policy and bounded C1 Pattern assertions are delivered. C2, broader parameter projection and runtime
  parameter enforcement remain separate work; container admission does not imply element/value assertions.

## Maintainer decisions and tracker ownership

Hive owns tracker reconciliation and receives the detailed issue audit through the worker handoff, outside this repository.
It decides when to refresh descriptions and whether retained loading/projection work belongs in these parents or separately
scoped follow-ups. This record authorizes no new scope, acceptance change, issue closure, label or milestone update.

Repository delivery does not establish a release or current adopter qualification. Consumer-specific acceptance and any
new grammar/projection admission still need their own evidence and maintainer decision. No additional technical decision
is required for this documentation cleanup; PR review and merge remain separate.
